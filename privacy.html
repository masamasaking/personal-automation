プライバシーポリシー

制定日: 2026年10月17日

対象

このポリシーは、運用者個人が自分の業務のために使う自動化ツール（以下「本ツール」）に適用されます。本ツールの利用者は本人だけで、一般には提供していません。

取得する情報

本ツールは、Google の権限「メールの閲覧（gmail.readonly）」を使い、本人の Gmail の受信箱にある未読メールのうち最新15件について、差出人の表示名・件名・日時・自動配信かどうかの判定に使うヘッダだけを読み取ります。メールの本文と添付ファイルは読み取りません。

利用目的

読み取った情報は、本人向けの毎朝の予定確認（朝のまとめ）を作るためだけに使います。

保存と共有

  • 読み取った情報は、本人が管理する端末で朝のまとめを作る間だけ扱い、まとめの文章の一部として本人の作業記録に残ることがあります。
  • 第三者に販売・提供することはありません。広告には使いません。
  • 朝のまとめの文章を作る際、本人が契約している AI サービスで処理することがあります。

メールの操作

本ツールはメールを送信・変更・削除・移動しません。読み取り専用の権限だけを使います。

権限の取り消し

Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」から、いつでも本ツールへのアクセス権を削除できます。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用と他のアプリへの転送は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。
